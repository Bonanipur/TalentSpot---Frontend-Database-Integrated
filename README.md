# 🏆 TalentSpot

**AI-powered sports talent identification and assessment platform.**

TalentSpot helps identify emerging athletes through structured assessments and AI-assisted performance analysis.

### ✨ Features

* 👤 Athlete registration & profiles
* 🏃 Sprint, jump & agility assessments
* 🤖 AI-assisted pose analysis
* 📊 Performance scoring & results
* 📈 Athlete dashboard & talent insights

### 🛠️ Tech Stack

**React • TypeScript • Vite • Tailwind CSS • Supabase**

### 🚀 Run Locally

```bash
npm install
npm run dev
```

> **Demo Prototype:** This repository currently uses mock data to demonstrate the complete athlete assessment workflow.
